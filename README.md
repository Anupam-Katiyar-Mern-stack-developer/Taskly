# Taskly — Plan less. Do more.

A simple, beginner-friendly **MERN Task Manager** that helps users manage their daily tasks.

## About

Taskly is a multi-user task management web application where users can register, log in, and manage their personal tasks.

This project is being built to learn full-stack web development using the MERN stack, from development setup to deployment.

## Features

- User registration and login
- Create new tasks
- View all personal tasks
- Edit existing tasks
- Mark tasks as completed or incomplete
- Delete tasks
- Responsive user interface

## Tech Stack

- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcrypt
- **Tools:** Git, GitHub, Postman

## Project Goal

Build a complete beginner-friendly full-stack application while learning React, Node.js, Express.js, MongoDB, authentication, API development, and deployment.
